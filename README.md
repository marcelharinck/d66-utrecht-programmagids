# D66 Utrecht Programmagids 2027–2031

Een openbare leeswijzer bij het conceptverkiezingsprogramma van D66 Provincie Utrecht van 1 oktober 2026.

De gids bevat vijf gebiedsroutes en twaalf inhoudelijke leesroutes. Iedere route heeft vier onderdelen: programmapunten, samenhang, rolverdeling en keuzes en grenzen. De samenvattingen zijn gekoppeld aan de gedrukte paginanummers in het concept. De brontekst en het oorspronkelijke PDF-bestand zijn beschikbaar in de gids.

Dit is een leeswijzer met samenvattingen en duiding, geen vastgesteld verkiezingsprogramma. De gebiedsindeling is geen formele indeling van D66-afdelingen.

## Openen

[Open de programmagids](https://marcelharinck.github.io/d66-utrecht-programmagids/).

Lokaal kun je `index.html` in een browser openen. Houd `conceptprogramma.pdf` in dezelfde map. Er is geen installatie of internetverbinding nodig. De gekozen leesroute wordt op het apparaat onthouden.

## Publicatie

GitHub Pages publiceert de bestanden uit de hoofdmap van de branch `main`. De site bestaat uit statische HTML, CSS en JavaScript en heeft geen bouwstap of server nodig. `.nojekyll` zorgt dat de bestanden direct worden gepubliceerd.

## Bron

[Officiële publicatie van het conceptprogramma](https://d66.nl/provincieutrecht/nieuws/concept-verkiezingsprogramma/).

Het oorspronkelijke programma en het D66-logo blijven materiaal van D66. De lettertypen zijn Inter. Deze repository bevat geen aanvullende analytics of externe scripts.
